# Coffee Haven

A coffee menu page built with HTML & CSS.

Practice project.

## Preview

![Coffee Haven Preview](./Preveiw_Coffee_Haven_Page.jpg)

## About

Coffee Haven — Artisan Coffee & Espresso Bar. A menu with 4 coffee cards: Espresso, Latte, Cappuccino and Americano, each with a photo, a badge, a description, a price and an Add to cart button.

## Tech

- HTML
- CSS (Flexbox)

## How to open

Open index.html in your browser.
